Principles

  • Simple first. Server-rendered HTML that works without JavaScript; fp-ui.js only enhances (menus, dialogs, tabs).
  • Honest. One primary action per screen, no fake urgency, no pre-ticked boxes, no shaming copy on "no".
  • Readable. 16px body, 68ch lines, 4.5:1 contrast for text, 3:1 for controls and large text.
  • Framasoft. Violet for actions, orange for accents, Tovari Sans for h1/h2 and big numbers only.
  • Tokens, never raw values. Components use var(--fp-*); page CSS goes in its own file, not in fp-components.css.

Ratio against white, computed from fp-tokens.css. Below 4.5:1: borders, large text or backgrounds only.

Typography

System fonts for text (no download); Tovari Sans (Framasoft's typeface, vendored, OFL) for h1, h2, .fp-kicker, the brand and counters. Never below 20px.

Spacing, radii, shadows

4px base: --fp-s1 4, s2 8, s3 12, s4 16, s5 20, s6 24, s8 32, s10 40, s12 48, s16 64, s20 80. Inside a component: s1–s4. Between components: s4–s8. Between sections: s10–s16.

Breakpoints (Bootstrap 4): 576 / 768 / 992 / 1200px. Write mobile-first @media (min-width: 768px). Pages are checked at 375, 768, 1024 and 1440px with no horizontal scroll.

Buttons

One primary per view (the action we hope for). Secondary for alternatives, tertiary for cancel/back/low-stakes, danger only for irreversible actions, always behind a confirmation. Use <button> for actions, <a> for navigation. 44px tall; -sm only in dense tables.

Dialog

Native <dialog>: focus trap, Escape and backdrop come from the browser. The opener is a real link or form fallback (here href="#sg-dialog"); data-fp-dialog-open upgrades it. Only for short confirmations or forms; never to interrupt someone who is signing.
